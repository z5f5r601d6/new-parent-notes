# 做试管婴儿冻胚移植前需要做哪些检查？

> 更新时间：2026-09-15 (UTC+8)

冻胚移植前的检查旨在评估母体身体状态、子宫内膜容受性及排除潜在风险，确保移植条件 optimal。以下是具体检查项目及注意事项，按系统分类说明：

　　**一、生殖系统核心检查**

　　1. **子宫内膜评估**

　　**超声检查**：需测量双层内膜厚度，一般要求≥7mm(优质 8~12mm)，过薄可能影响着床;同时观察内膜形态，判断是否存在三线征清晰、有无息肉、粘连或肌瘤等异常(如宫腔粘连需先手术处理)。部分中心会通过彩色多普勒检测内膜血流阻力指数(RI)，RI 过高提示血供不足，可能需药物改善(如阿司匹林、西地那非)。

　　**宫腔镜（必要时）**：若超声发现内膜异常(如息肉、回声不均)，需行宫腔镜检查及治疗，清除病灶后再安排移植(研究显示宫腔镜可使着床率提高约 15%~20%)。

　　2. **激素水平检测**

　　**雌二醇（E₂）与孕酮（P）**：人工周期移植需通过药物模拟自然周期激素变化，移植前需确认 E₂水平(通常>150pg/ml)和孕酮值(排卵后周期需<1ng/ml，避免提前黄体化)。若孕酮升高(如>2ng/ml)，可能提示内膜过早转化，需调整用药或取消周期。

　　**其他激素**：如促甲状腺激素(TSH)需控制在<2.5mIU/L(孕早期标准)，高泌乳素血症患者需复查泌乳素(PRL)是否正常。

　　**二、全身健康状况检查**

　　1. **感染性疾病筛查**

　　**必查项目**：包括乙肝五项、丙肝抗体、梅毒血清学检测、HIV 抗体，确保无母婴传播风险(部分医院要求近 3 个月内结果)。

　　**可选项目**：若有反复阴道炎史，需查白带常规、支原体、衣原体(阳性需治疗至转阴)。

　　2. **基础疾病评估**

　　**血液检查**：包括血常规(排除贫血)、凝血功能(如 D - 二聚体升高可能提示高凝状态，需抗凝治疗)、肝肾功能。

　　**慢性病管理**：糖尿病患者需复查空腹血糖及糖化血红蛋白(HbA1c<6.5%)，高血压患者需控制血压<140/90mmHg。

　　3. **免疫与血栓风险检查（适用于反复移植失败患者）**

　　**免疫指标**：如抗核抗体(ANA)、抗心磷脂抗体(ACA)、β₂- 糖蛋白 Ⅰ 抗体等(阳性可能提示免疫紊乱，需免疫抑制治疗)。

　　**血栓前状态检测**：包括同型半胱氨酸(Hcy，>10μmol/L 需补充叶酸 + 维生素 B₁₂)、蛋白 C/S 活性、抗凝血酶 Ⅲ 等。

　　**三、用药与个体化准备**

　　1. **药物方案确认**

　　**内膜准备方案**：

　　**自然周期**：适用于月经规律者，需通过超声监测卵泡发育及内膜生长，排卵后确定移植日期。

　　**人工周期**：使用雌激素(如戊酸雌二醇、芬吗通)刺激内膜，需按医嘱定时服药，避免漏服导致激素波动。

　　**降调节周期**：适用于子宫内膜异位症或薄型内膜患者，需先注射 GnRH-a(如达菲林)抑制内源性激素，再进行内膜准备。

　　**黄体支持药物**：移植前需确认黄体酮剂型(如阴道凝胶、肌注黄体酮、口服地屈孕酮)及用药时间，确保黄体功能充足。

　　2. **生活方式调整**

　　**避免性生活**：移植前 3~5 天避免同房，减少盆腔充血及感染风险。

　　**停止剧烈运动**：避免腹部受压或增加腹压的活动(如卷腹、提重物)，可适度散步促进血液循环。

　　**心理状态调节**：若焦虑情绪明显，可通过冥想、心理咨询等方式缓解压力(研究显示心理压力可能降低着床率约 12%)。

　　**四、特殊情况额外检查**

　　1. **复发性流产或多次移植失败史**

　　需增加 **胚胎植入前遗传学检测（PGT）**：排除胚胎染色体异常导致的着床失败。

　　宫腔镜检查 + 内膜活检：评估内膜炎症细胞(如 CD38/CD138 阳性细胞)，排除慢性子宫内膜炎。

　　2. **高龄或卵巢储备下降患者**

　　复查 **抗缪勒管激素（AMH）** 及窦卵泡计数(AFC)：评估剩余胚胎是否足够，必要时调整移植策略(如单囊胚移植降低多胎风险)。

　　3. **冷冻胚胎类型**

　　**卵裂期胚胎（第 3 天胚胎）**：需确认内膜同步至月经周期第 11~12 天状态。

　　**囊胚（第 5~6 天胚胎）**：内膜准备需延长至月经周期第 16~18 天(或人工周期雌激素用药第 10~12 天)，使内膜更成熟。

　　**五、检查时间与注意事项**

　　冻胚移植前检查需遵循 “个体化” 原则，不同生殖中心流程可能略有差异，建议提前与主治医生沟通确认。关键在于：

　　**内膜条件达标**：通过超声和激素调控，确保内膜厚度、形态及血流符合移植要求。

　　**全身状态稳定**：控制基础疾病，排除感染、血栓及免疫异常等风险因素。

　　**心理与生理协同准备**：避免过度焦虑，严格按医嘱用药及复诊，同时调整生活方式(如避免剧烈运动、保持规律作息)。

　　规范的术前评估可使冻胚移植临床妊娠率提升至 **50%~65%**(因年龄、胚胎质量而异)，是试管婴儿成功的重要保障环节。
