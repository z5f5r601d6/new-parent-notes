# 就医体验再升级  市一院介入超声科标准化手术室正式启用

> 更新时间：2026-09-17 (UTC+8)

6月2日，淮安市第一人民医院介入超声科标准化手术室正式启用。院党委书记徐克平、院长杨晓钟、副院长于亮、高勇出席启用仪式并揭牌，医院部分职能部门负责人及超声科医护人员参与仪式。仪式由医务处处长张红主持。

✦

✦

✦

       启用仪式上，院党委书记徐克平对介入超声科的工作给予了充分肯定。他说，淮安市一院介入超声科已集聚了一批阵容强大、专业技术过硬的医疗团队，诊疗数量每年可达7000余例，拥有成熟的诊疗技术和丰富的临床经验。此次标准化手术室的启用，更为超声介入诊疗插上了腾飞的“翅膀”。

       近年来，随着超声医学的快速发展，目前已成为独立的临床学科，在临床诊疗的决策中发挥着越来越重要的作用。介入超声作为现代超声医学的重要分支，是医疗走向精准化、微创化的重要标志，具有操作简便、费用低廉、损伤小、恢复快、治疗效果确切等优势，深受患者青睐。

✦

✦

✦

       徐长松主任还为大家介绍了超声介入团队目前开展的工作、介入超声标准化手术室启用的背景和意义，随后陪同徐克平书记一行参观了介入超声标准化手术室，并详细介绍了手术室的布局、手术间的配置要求、介入手术的流程以及介入团队的组成情况、手术业绩等。

✦

✦

✦

       据了解，介入超声标准化手术室实施闭环管理，分为手术室、术后观察室以及准备室三部分，医生、患者、污物三通道分离。手术室内无影灯、心电监护设备、麻醉设备等一应俱全，可开展消融等四级介入手术。标准化手术室每天接纳的就诊人次可达30-40例，相较之前有所提升。这样的设置不仅规范了患者的就诊流程，使患者有序分流，更可一站式直达急诊抢救室，大大改善了就医环境，提升了患者的就医体验。

✦

✦

二、多模态融合影像精准导航下介入诊断与治疗

三、穿刺活检、超声造影诊断多脏器占位病变

四、全身多脏器囊肿的囊液抽吸固化治疗，包括肝、肾、卵巢、甲状腺、乳腺等
